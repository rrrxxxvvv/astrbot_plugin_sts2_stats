# 尖塔统计 · astrbot_plugin_sts2_stats

AstrBot 的《杀戮尖塔 2》资料与社区胜率查询插件。从 `astrbot_plugin_geda` 拆出，可独立安装，无需原插件、LLM 或 API Key。基础图鉴、胜率与排行均使用 **Spire Codex** 数据。

## 功能

- 查询卡牌、遗物、怪物、药水、事件、能力和角色，支持名称、英文 ID 和模糊匹配。
- 生成详情图片，展示原图、说明和相应属性；卡牌展示升级信息，怪物展示行动信息，具体字段取决于数据源。
- 卡牌、遗物详情附社区胜率，也可单独查看统计图：胜率、胜场、样本数、选取率，以及可用的 SOLO 单人 / P2 双人统计。
- 批量查询最多 6 个条目并拼接详情图片；有歧义时先选择候选，再继续处理剩余条目。同名卡牌与能力优先命中卡牌。
- 按角色、通用牌、无色牌、诅咒牌、多人牌、遗物或先古来源生成胜率排行，支持从高到低、从低到高两种顺序。
- 数据与图片本地缓存、请求限速；统计接口失败时优先使用已有旧统计缓存，部分接口不可用时尽量保留其余统计。

## 安装与迁移

可在 AstrBot 插件管理中使用仓库地址 `https://github.com/rrrxxxvvv/astrbot_plugin_sts2_stats` 安装，也可按以下步骤手动安装。

1. 将本目录放入 AstrBot 的 `data/plugins/astrbot_plugin_sts2_stats`。
2. 在 **AstrBot 使用的 Python 环境**安装依赖：`python -m pip install -r data/plugins/astrbot_plugin_sts2_stats/requirements.txt`。
3. 重启 AstrBot 或重载插件，在配置页调整参数，发送 `/尖塔` 验证。

依赖 `aiohttp>=3.9.0`、`Pillow>=10.0.0`，不需要 matplotlib。代码使用 Python 3.10+ 语法，实际 Python 版本以当前 AstrBot 的要求为准。需要适配器支持发送图片；命令前缀以 AstrBot 的设置为准，下文以 `/` 为例。

此目录是独立提取版，原疙瘩插件未被修改。**同时加载两者可能重复注册尖塔指令**；正式迁移时应从旧插件移除尖塔模块的导入及 Mixin 注册，或停用旧插件。仅将旧版 `sts2_enabled` 设为 false 仍会保留旧命令处理器，不能保证消除冲突。也应检查其他插件是否占用 `/选择`、`/愤怒`、`/从夯到拉` 等指令。

新插件采用独立配置，不自动读取旧插件配置。可将旧配置 `SlaySpire` 分组中的同名字段填入新插件；代码也兼容原分组格式。旧版未实际生效的 `sts2_power_table_include_multiplayer` 不再提供，多人牌请使用专门的“多人”排行。

## 指令与示例

| 指令 | 功能 / 示例 |
| --- | --- |
| `/尖塔` | 图片帮助；别名 `/杀戮尖塔`、`/尖塔帮助`、`/塔` |
| `/尖塔 <关键词>` | 全类型查询，例如 `/尖塔 愤怒` |
| `/尖塔查询 <关键词>` | 全类型查询，别名 `/尖塔搜索` |
| `/尖塔卡牌 <关键词>` | 卡牌查询，例如 `/尖塔卡牌 ANGER` |
| `/尖塔遗物 <关键词>` | 遗物查询 |
| `/尖塔怪物 <关键词>` | 怪物属性、描述及行动信息 |
| `/尖塔药水 <关键词>` | 药水查询 |
| `/尖塔事件 <关键词>` | 事件描述与选项 |
| `/尖塔能力 <关键词>` | 能力、增益与减益查询 |
| `/尖塔角色 <关键词>` | 角色查询 |
| `/尖塔选择 <序号>` | 选择候选；别名 `/尖塔选`、`/选择`，默认有效期 30 秒 |
| `/尖塔胜率 <卡牌或遗物名>` | 独立统计图，默认 A10 |
| `/从夯到拉 <范围>` | 胜率从高到低排行，例如 `/从夯到拉 战士` |
| `/从拉到夯 <范围>` | 胜率从低到高排行，例如 `/从拉到夯 遗物` |
| `/尖塔刷新` | 强制重新请求七类基础图鉴；不等同于清空统计和图片缓存 |
| `/尖塔 reset` | 清空数据缓存和待选择状态，保留卡图缓存；也支持 `重置`、`清缓存`、`清空缓存`、`重置缓存` |
| `/愤怒` | 保留的快捷文本指令，返回 `card ANGER discard`，不执行游戏操作 |

分类查询以及“尖塔查询 / 尖塔搜索”也支持省略关键词前空格，例如 `/尖塔卡牌愤怒`。

批量示例：`/尖塔查询 愤怒,打击`。可使用空格、英文/中文逗号、顿号、分号或换行分隔，最多处理前 6 项。含空格的英文名称也会被拆分，建议使用中文名或不含空格的英文 ID。候选选择按会话和发送者隔离，必须由原查询者在同一会话中回复。

### 排行范围与统计口径

- 角色：`战士`、`猎人`、`储君`、`骨妹`、`鸡煲`；支持铁甲战士、静默猎手、亡灵契约师、故障机器人等别名及 `ironclad`、`silent`、`regent`、`necrobinder`、`defect`。
- 公共分类：`通用`（无色、通用先古及诅咒卡）、`无色`、`诅咒`、`多人`、`遗物`。
- 先古遗物：`涅奥`、`欧洛巴斯`、`佩尔`、`特兹卡塔拉`、`诺奴佩普`、`坦克斯`、`瓦库`、`达弗`。例如 `/从夯到拉 涅奥` 会将各角色的遗物排行拼接展示；`/从夯到拉 先古` 返回来源提示。

排行固定使用 **A10**：普通分类为 `solo:a10` 单人样本，角色牌还按对应角色筛选；“多人”为 `2p:a10` 双人样本，不混入普通角色排行。默认过滤少于 100 次 `picks` 的条目，每张表最多展示 120 条。排序依据上游 `win_rate`，同胜率时参考样本数，并非上游 Elo 或本地强度评分。

`sts2_default_ascension` 只影响单条胜率查询和详情附带统计，不改变排行的固定 A10。单条统计读取 `aN` 总体分组，并展示接口提供的单人、双人分组。胜率和选取率沿用上游口径；没有 `pick_rate` 时，部分展示会以样本数 / 总对局数作为出现率回退。社区上传样本不是所有玩家的总体统计，也不等于选择某张卡就能获得对应胜率。缺失数据会显示“暂无”或提示，不应视为 0% 胜率。

## 配置

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `sts2_enabled` | `true` | 启停全部功能 |
| `sts2_api_base` | `https://spire-codex.com/api` | 图鉴和统计共同使用的 API 根地址，可配置兼容反代 |
| `sts2_lang` | `zhs` | 数据语言，默认简体中文 |
| `sts2_request_timeout` | `15` | 客户端请求超时，秒 |
| `sts2_rate_limit_per_min` | `50` | 本地 API 请求限速，每分钟 |
| `sts2_cache_ttl_hours` | `120` | 图鉴与统计缓存有效期，小时 |
| `sts2_select_timeout_sec` | `30` | 候选选择有效期，秒 |
| `sts2_max_list_results` | `10` | 候选列表上限，限制在 1–20 |
| `sts2_default_ascension` | `10` | 单条统计进阶等级 |
| `sts2_power_table_limit` | `120` | 每张排行上限，限制在 10–200；兼容旧值 30 时按 120 处理 |
| `sts2_power_table_min_picks` | `100` | 排行最小样本数 |
| `cjk_font_path` | 空 | 中文字体文件绝对路径，可选 |

运行数据存于 AstrBot 工作目录下的 `data/plugin_data/astrbot_plugin_sts2_stats/`：`sts2_cache.json` 为数据缓存，`sts2_icon_cache/` 为远程图像缓存，`sts2_images/` 为生成图片，`fonts/` 为自动下载字体。无需迁移旧缓存，可自动重新获取。

中文显示为方框时，配置已有中文字体，或在 Linux 安装 `fonts-noto-cjk` / `fonts-wqy-microhei`。插件先查找系统字体和本地字体缓存，找不到时尝试从 jsDelivr / SourceForge 下载；网络受限时应手动提供字体。图片下载不经过图鉴 API 的限速器，批量图标下载最多 8 路并发。

## API 依赖与感谢

特别感谢 **[Spire Codex](https://spire-codex.com/)** 提供公开的《杀戮尖塔 2》图鉴、游戏图片和社区统计服务，以及上传对局的社区贡献者。这是本插件的核心数据依赖，基础资料和胜率均来自该服务。

默认 API 根地址为 `https://spire-codex.com/api`，实际调用由 `sts2/sts2_client.py` 实现：

| 接口（相对 API 根地址） | 用途 |
| --- | --- |
| `/cards`、`/relics`、`/monsters`、`/potions`、`/events`、`/powers`、`/characters` | 七类基础资料，携带 `lang` 参数 |
| `/runs/metrics/cards`、`/runs/metrics/relics` | 胜率、样本及选取率；按 `bracket`、可选 `character` 筛选 |
| `/runs/stats/{cards或relics}/{id}` | 单实体统计及分组明细 |
| 数据记录中的图片 URL | 卡面、遗物、怪物及角色图片；优先尝试中文卡面 |

客户端还保留 `/runs/list`、`/runs/stats`、`/runs/scores/{类型}` 的辅助方法，目前主命令不依赖这些方法。查询不上传聊天内容、游戏存档或个人战绩；会向数据源发送语言、实体 ID、统计分组等查询参数。数据源的可用性、字段和统计规则由上游维护，请合理设置缓存及限速。
